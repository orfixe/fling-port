# Changelog

All notable changes to this project will be documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0).

## [0.1.0] - 2026-11-21
### Added
- Linux: Tray/panel UI modeled on macOS Fling popover.
- Linux: Cast current Firefox tab via global shortcut Meta+Shift+C.
- Linux: Cast link from clipboard.
- Linux: Play/pause, ±30 s, volume, stop controls.
- Linux: Real now‑playing info via ADB.
- Linux: YouTube “Link with TV code” (live video + position).
- Linux: TV remote over network: power, app launcher, d‑pad, volume, typing, voice.
- Linux: Laptop as a Bluetooth LE HID remote.
- Linux: Terminal remote `fling-tui`.
- Linux: One‑click Connect TV window.
- Linux: Scroll/swipe anywhere = d‑pad.
- Linux: English/Russian UI.

- Android: Cast link from clipboard or the share sheet (auto-casts shared links); last 5 links.
- Android: Play/pause, ±30 s, volume, stop controls.
- Android: Real now‑playing info via ADB.
- Android: TV remote over network: power, app launcher, d‑pad, volume, typing, voice.
- Android: Touchpad mode — swipe = d‑pad, tap = OK, long press = Back.
- Android: Phone volume keys control TV.
- Android: Quick Settings tile “Pause on TV”.
- Android: English/Russian UI.
