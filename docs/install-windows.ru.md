# Fling для Windows и расширение для браузера — установка по шагам

← [Назад к README](../README.ru.md)

Fling — это значок рядом с часами, который отправляет видео из браузера на телевизор
(Chromecast / Google TV) и превращает компьютер в пульт: питание, приложения, стрелки,
громкость, ввод текста, голосовой поиск. Это неофициальный порт macOS-приложения
[Fling](https://github.com/tatianathevisionary/fling) от Damion Rashford и Tatiana.

Установка состоит из двух частей:

1. **Приложение Fling** на компьютере — оно разговаривает с телевизором.
2. **Расширение Fling** в браузере — оно говорит приложению, какая вкладка открыта,
   и даёт кнопку «на ТВ» прямо в браузере. Без расширения Fling тоже работает
   (ссылки из буфера, пульт), но «Отправить эту вкладку» знает только Firefox.

---

## Что нужно

| | |
|---|---|
| Windows | 10 (версия 1809 или новее) или 11, 64-бит. Ноутбуки на ARM (Snapdragon) — тоже, через встроенную эмуляцию Windows 11 |
| Телевизор | Chromecast, Google TV или телевизор со встроенным Android TV / Google TV (TCL, Sony, Philips, Hisense, Xiaomi…) |
| Сеть | компьютер и телевизор в **одной** сети (один роутер / Wi-Fi). Кабель или Wi-Fi — не важно |
| Права | администратор **не нужен**, всё ставится только для вашего пользователя |

## Часть 1. Приложение

Выберите **один** из двух способов.

### Способ А — готовая сборка (проще всего)

1. Откройте страницу [Releases](https://github.com/orfixe/fling-linux-android/releases)
   и скачайте **`Fling-Windows-…zip`** из последней версии.
2. Распакуйте архив в постоянное место, например `Документы\Fling`
   (не запускайте прямо из архива и не оставляйте в «Загрузках», которые вы чистите).
3. В распакованной папке дважды щёлкните **`Install shortcuts.cmd`**.
   Он добавит Fling в меню «Пуск», команду `fling` и сразу запустит программу.
   *(Можно и просто дважды щёлкнуть `Fling.exe` — тогда без ярлыка в «Пуске».)*
4. **Windows SmartScreen** может показать «Windows защитила ваш компьютер» — сборка
   не подписана платным сертификатом. Нажмите **Подробнее → Выполнить в любом случае**.
   Некоторые антивирусы (Касперский, ESET, Avast…) так же насторожённо относятся к
   неподписанным программам: если Fling.exe попал в карантин, добавьте папку Fling в исключения.

Python ставить не нужно — всё уже внутри.

### Способ Б — из исходников (для тех, кто хочет обновляться из git)

1. Скачайте репозиторий: зелёная кнопка **Code → Download ZIP** и распакуйте,
   или `git clone https://github.com/orfixe/fling-linux-android.git`.
2. Откройте папку `windows` и дважды щёлкните **`install.cmd`**.
3. Скрипт сам поставит всё нужное (≈ 300 МБ, 2–5 минут):
   менеджер Python [uv](https://docs.astral.sh/uv/), отдельный Python 3.12, Qt,
   движок трансляции [catt](https://github.com/skorokithakis/catt), ADB от Google.
   В конце Fling запустится.

Ничего в системе не меняется: всё лежит в `%LOCALAPPDATA%\Fling`, настройки — в
`%APPDATA%\Fling\fling.json`. Обновление — снова `install.cmd`. Удаление — `uninstall.cmd`.

### Первый запуск

1. **Брандмауэр Windows** спросит, разрешить ли Fling (или Python) доступ к сети —
   отметьте **Частные сети** и нажмите **Разрешить**. Без этого Fling не найдёт телевизор.
2. Значок Fling (синий квадрат с экраном) появится **справа внизу, у часов**. Если его
   не видно — нажмите стрелку **^** и перетащите значок на панель задач, чтобы он был всегда под рукой.
3. **Левый клик** — панель, **правый клик** — меню.
4. Через ~10 секунд внизу панели появится имя телевизора с зелёной точкой.
   Если нет — смотрите «Если что-то не работает» ниже.
5. Один раз откроется встроенная инструкция «Как пользоваться». Её всегда можно открыть снова из панели.

### Подключить пульт (один раз)

Чтобы работали питание, приложения, стрелки, ввод текста и голос:

1. В панели нажмите **«Связать пульт с ТВ…»**.
2. На телевизоре появится код из 6 символов — введите его (или нажимайте кнопки под полем).
3. Готово. Теперь в панели есть раздел «На телевизоре».

Хотите видеть настоящие название и обложку того, что играет на ТВ (Netflix, YouTube,
Spotify…)? Откройте **«Подключение ТВ…» → «Найти и подключить всё»** и включите ADB —
окно подскажет, что нажать на телевизоре.

## Часть 2. Расширение для браузера

Расширение — маленькая кнопка Fling на панели браузера: отправить вкладку, пауза,
перемотка, громкость, пульт. Плюс пункт «Отправить на ТВ» в меню правой кнопки
на ссылках и видео и сочетание **Alt+Shift+C**. Если видео на странице уже играет,
на ТВ оно продолжится с того же места.

Файлы расширения:
- в готовой сборке — папка `extension` внутри распакованного Fling;
- при установке из исходников — `%LOCALAPPDATA%\Fling\extension`;
- или отдельные архивы `fling-chrome-…zip` / `fling-firefox-…zip` на странице Releases.

### Chrome, Edge, Яндекс Браузер, Brave, Opera, Vivaldi

1. Откройте страницу расширений:
   Chrome — `chrome://extensions`, Edge — `edge://extensions`,
   Яндекс — `browser://extensions`, Opera — `opera://extensions`.
2. Включите **«Режим разработчика»** (переключатель справа вверху; в Edge — слева внизу).
3. Нажмите **«Загрузить распакованное расширение»** и выберите папку **`extension\chrome`**.
4. Нажмите значок пазла 🧩 на панели браузера и **закрепите** Fling (кнопка-булавка).
5. Щёлкните кнопку Fling — если в окошке зелёная точка и имя телевизора, всё работает.

> Chrome иногда показывает «Отключите расширения в режиме разработчика» — это просто
> напоминание, нажмите «×». Расширение остаётся.
> Папку `extension\chrome` не удаляйте и не перемещайте — браузер загружает расширение из неё.

### Firefox

Пока расширение не опубликовано в каталоге Mozilla, Firefox ставит его только временно
(до перезапуска браузера):

1. Откройте `about:debugging#/runtime/this-firefox`.
2. **«Загрузить временное дополнение…»** → выберите `fling-firefox-…zip`
   (или файл `manifest.json` в папке `extension\firefox`).

Постоянно — в Firefox Developer Edition / Nightly: в `about:config` поставьте
`xpinstall.signatures.required` = `false`, затем `about:addons` → ⚙ → **«Установить дополнение из файла…»** → zip.

Без расширения Fling всё равно умеет брать активную вкладку Firefox из файла сессии
(с задержкой до 15 секунд).

### Safari (Mac)

Safari есть только на Mac, поэтому расширение для него работает с Fling, запущенным
на этом же Mac (из исходников: `python3 desktop/fling_app.py`; кроме того, у оригинального
macOS-Fling своя связка с Safari, расширение ему не нужно). Сборка требует Xcode:

```sh
./extension/safari/build-safari.sh
```

Затем: откройте получившееся приложение `extension/dist/safari-app/Fling.app` один раз,
в Safari → Настройки → Дополнения включите «Показывать функции для веб-разработчиков»,
в меню «Разработка» — «Разрешить неподписанные расширения», и в Настройки → Расширения
включите Fling.

### Настройки расширения

Правый клик по кнопке Fling → «Параметры»:
- **Сообщать приложению Fling, какая вкладка открыта** — нужно, чтобы кнопка
  «Отправить эту вкладку» в панели и общее сочетание клавиш работали с этим браузером.
  Адрес уходит **только** в Fling на этом компьютере (127.0.0.1), не в интернет.
  Приватные окна не передаются никогда.
- **Ставить видео на паузу после отправки** — чтобы звук не шёл дважды.
- **Уведомлять о смене видео** — тот же переключатель, что в панели.

## Как пользоваться (коротко)

| Что | Как |
|---|---|
| Отправить вкладку на ТВ | кнопка Fling в браузере, **Alt+Shift+C** в браузере, или **Win+Shift+C** где угодно (если это сочетание занято другой программой — **Ctrl+Alt+Shift+C**; панель показывает, какое работает) |
| Отправить ссылку | скопируйте её → «Отправить скопированную ссылку», или правый клик по ссылке → «Отправить ссылку на ТВ» |
| Пауза / перемотка | Пробел, ← / → в панели или в окошке расширения |
| Стрелки на ТВ | крестовина в панели, или крутите колёсико / тачпад над панелью |
| Уведомления о смене видео / трека | включены по умолчанию (зелёный колокольчик); выключить — нажмите «Уведомлять о смене видео» (колокольчик станет красным) |
| Язык, компактный вид | флажки 🇬🇧 / 🇷🇺, кнопка ⤡ и **?** (инструкция) в правом верхнем углу панели |
| Автозапуск с Windows | «Запускать при входе» |
| Команды | `fling`, `fling setup`, `fling cast-tab`, `fling clip`, `fling screenshot`, `fling help`, `fling quit` (в новом окне PowerShell / cmd) |

Что можно отправить: YouTube, прямые ссылки на файлы (mp4, mkv, webm, mp3, m3u8…) и
большинство видеосайтов. Обычные страницы и сервисы с защитой (Netflix и т. п.) — нет;
их можно запустить на ТВ кнопками приложений и управлять пультом.

## Если что-то не работает

| Что видите | Что сделать |
|---|---|
| «Устройство не найдено» | Компьютер и ТВ в одной сети? Разрешите Fling/Python в брандмауэре: Пуск → «Брандмауэр Защитника Windows» → «Разрешение взаимодействия с приложением…» → отметьте «Частные». VPN, гостевой Wi-Fi и «изоляция клиентов» на роутере мешают поиску — добавьте ТВ вручную: кнопка **«ТВ…»** внизу панели → «Добавить ТВ по IP…» (IP — в настройках сети телевизора) |
| Сеть отмечена как «Общедоступная» | Параметры → Сеть и Интернет → ваша сеть → **Частная сеть** |
| В расширении «Приложение Fling не запущено» | Запустите Fling из «Пуска». Если не помогает — другая программа заняла порт 47613: поменяйте `"bridge_port"` в `%APPDATA%\Fling\fling.json` и тот же порт в настройках расширения |
| «Отправить эту вкладку» серая | Поставьте расширение (Часть 2) и откройте вкладку с видео |
| Пауза на YouTube не срабатывает | Подключите пульт («Связать пульт с ТВ…») — YouTube на ТВ игнорирует паузу по Chromecast |
| Микрофон молчит | Параметры → Конфиденциальность и защита → Микрофон → включите «Разрешить классическим приложениям». У ноутбуков с «умными» микрофонами (Realtek, Intel, AMD, Dolby) выключите в их фирменной программе эффекты шумоподавления, если голос не распознаётся |
| Сочетание Win+Shift+C не работает | Его забрала другая программа (часто фирменные утилиты ноутбука, оверлеи NVIDIA/AMD). Fling сам переходит на Ctrl+Alt+Shift+C — сочетание видно в панели |
| Углы панели чёрные (удалённый рабочий стол, виртуальная машина, старый видеодрайвер) | Fling обычно сам это замечает. Если нет — добавьте `"solid_panel": true` в `%APPDATA%\Fling\fling.json` и перезапустите |
| Значок не появился | Нажмите **^** у часов. Если Fling не запустился — посмотрите журнал |
| Антивирус удалил Fling.exe | Восстановите из карантина и добавьте папку в исключения, или используйте способ Б (из исходников) |

**Журнал:** `%LOCALAPPDATA%\Fling\logs\app.log` — при сообщении о проблеме приложите последние строки.

## Обновление и удаление

- **Готовая сборка:** скачайте новый zip, закройте Fling (меню значка → «Выйти»),
  замените содержимое папки. Пульт и настройки сохранятся.
  Удалить: `powershell -ExecutionPolicy Bypass -File setup-shortcuts.ps1 -Remove` в папке Fling, затем удалите папку.
- **Из исходников:** обновить — `git pull` и снова `windows\install.cmd`; удалить — `windows\uninstall.cmd`.
- Расширение удаляется на странице расширений браузера.
- Телевизор будет помнить пульт «Fling (Windows)» — его можно удалить в настройках ТВ (не обязательно).

## Приватность

Всё происходит в вашей домашней сети. Fling обращается только к телевизору и к
youtube.com (названия и обложки). Расширение отправляет адрес вкладки только приложению
Fling на этом же компьютере. Никакой аналитики, аккаунтов и серверов.
