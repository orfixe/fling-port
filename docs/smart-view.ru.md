# Smart View — телевизоры Samsung и дисплеи Miracast

[English version](smart-view.md)

Fling для Windows и Linux работает с телевизорами Samsung (Tizen, 2016 года и новее) и с любыми
дисплеями Miracast прямо в основной панели. Отдельного окна нет: такие ТВ появляются в обычном
списке телевизоров рядом с Chromecast и Google TV.

## Что умеет

| | Samsung в той же сети | Дисплей Miracast по Wi‑Fi Direct (например, ТВ в отеле) |
|---|:---:|:---:|
| **Зеркалировать экран** — весь экран компьютера на ТВ | ✓ | ✓ |
| «Только ТВ» / «Расширить» / «Дублировать» (Windows), выбор запоминается | ✓ | ✓ |
| Экран ТВ сам переключается в самый большой режим 16:9 (Windows) | ✓ | ✓ |
| Пульт панели: стрелки, OK, назад, домой, громкость, без звука, каналы, ввод текста | ✓ | — |
| Приложения из панели (YouTube, Netflix, Prime Video, Disney+, Spotify, Plex…) | ✓ | — |
| Включение ТВ по сети (Wake-on-LAN) | ✓ ¹ | — |
| Видео, музыка, фото с компьютера и медиассылки — по DLNA | ✓ | — |
| Другие ссылки: YouTube открывается в приложении YouTube на ТВ, остальное — в браузере ТВ | ✓ | — |

<sub>¹ нужна настройка «Включение с моб. устройства» на ТВ (см. ниже).</sub>

## Как это работает

- **Зеркалирование — это Miracast (Wi‑Fi Display)**, то же, чем пользуется Smart View от Samsung.
  Fling сам видео не передаёт: в Windows он открывает системную панель «Трансляция» (Win+K) и сам
  выбирает в ней ТВ, в Linux — обращается к
  [GNOME Network Displays](https://gitlab.gnome.org/GNOME/gnome-network-displays) через D-Bus.
- **Wi‑Fi Direct не нужна общая сеть.** Гостевой и гостиничный Wi‑Fi обычно изолирует устройства
  друг от друга, поэтому обычный поиск ничего не находит, — но Windows всё равно видит дисплеи
  Miracast поблизости по Wi‑Fi Direct, и Fling показывает их как «Miracast · Wi‑Fi Direct». Для
  них работает только зеркалирование; пульту, приложениям и файлам нужна общая сеть с ТВ.
- **Пульт Samsung** — собственный сетевой пульт телевизора (WebSocket на порту 8002, на старых
  моделях 8001). В первый раз ТВ спросит, разрешить ли «Fling (Windows)», — нажмите
  **«Разрешить»** пультом ТВ. Fling запоминает выданный телевизором ключ и больше не спрашивает.
- **Файлы** идут по DLNA: Fling раздаёт только выбранный файл с маленького локального веб-сервера,
  который отвечает только адресу ТВ, на который файл отправлен; новый файл заменяет прежний.
- **Разрешение.** Windows часто выставляет телевизору по Miracast режим 4:3, например 1152×864, —
  картинка огромная и растянутая. После «Зеркалировать экран» Fling ждёт, когда появится экран ТВ,
  и переключает его в самый большой режим 16:9, который предлагает ТВ (по Miracast обычно
  1920×1080; 2K/4K — если их предлагают ТВ и Windows). Уже подключённые экраны Fling не трогает.

## Что нужно

- **Windows**: компьютер должен поддерживать Miracast (Wi‑Fi и видеодрайвер с «Беспроводным
  дисплеем»). Проверка: `netsh wlan show drivers` → «Поддерживается беспроводной дисплей: Да».
- **Linux**: установите GNOME Network Displays (магазин приложений дистрибутива или Flathub).
- **Телевизор**: для зеркалирования включите ТВ; на некоторых моделях нужно открыть источник
  «Screen Mirroring». Для включения по сети: «Настройки → Общие → Сеть → Экспертные настройки →
  Включение с моб. устройства».

## Если что-то не так

| Проблема | Что сделать |
|---|---|
| ТВ нет в списке | Включите его и нажмите **«Выбрать»** → «Искать снова». В сети отеля работает только Wi‑Fi Direct: проверьте, что Wi‑Fi на компьютере включён. |
| Не пропадает «Нажмите «Разрешить» на экране ТВ» | Посмотрите на ТВ: там запрос от Fling. Если нажали «Запретить»: «Настройки → Общие → Диспетчер внешних устройств → Диспетчер подключения устройств» → разрешите Fling. |
| Картинка на ТВ растянута | Нажмите в панели «Только ТВ» или «Расширить». В режиме «Дублировать» Windows передаёт пропорции ноутбука (часто 16:10), и ТВ их растягивает. |
| Панель «Трансляция» открылась, но ТВ не выбран | Выберите ТВ в ней вручную — разрешение Fling всё равно поправит. |
