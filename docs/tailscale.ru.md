# Удалённый доступ через Tailscale

[In English](tailscale.md)

С [Tailscale](https://tailscale.com) Fling управляет телевизором откуда угодно: с работы, из
поездки или с телефона через мобильный интернет. В Fling нет своего VPN: он опирается на
официальные приложения Tailscale и только **читает** состояние Tailscale на компьютере
(`tailscale status --json`, `tailscale ping`). Fling никогда не запускает `tailscale up`,
`down`, `set` или `logout`, не меняет настройки вашей сети Tailscale, ничего не открывает
в интернет и не пробрасывает порты.

## 1. Установите Tailscale (только из официальных источников)

| Устройство | Где взять |
|---|---|
| Windows, macOS, Linux | [tailscale.com/download](https://tailscale.com/download) |
| Телефон на Android | Google Play: **Tailscale** (пакет `com.tailscale.ipn`) |
| Android TV / Google TV | Google Play на ТВ: **Tailscale** — или **«Каталог»** в Fling («Инструменты…» → «Каталог» или «Настройки» → «Удалённый доступ» → «Установить Tailscale на ТВ…»): официальный APK, проверенный и установленный через ADB, пока вы дома |

Войдите в **один и тот же аккаунт** на всех устройствах. На ТВ откройте Tailscale, войдите
(он покажет код или QR-код для подтверждения с телефона) и включите его. В настройках
Tailscale на ТВ включите постоянное подключение / запуск при включении, чтобы ТВ оставался
доступен после перезагрузки.

## 2. Добавьте ТВ в Fling

**Компьютер.** Откройте окно выбора ТВ («Выбрать» внизу панели). В группе **«Через Tailscale»**
перечислены телевизоры вашей сети Tailscale и видно, кто в сети; нажмите **«Добавить»**. Можно
и ввести адрес Tailscale в поле «Добавить по IP»: `100.x.y.z` или имя MagicDNS (`living-room`
или `living-room.ваша-сеть.ts.net`). Fling проверит, отвечают ли Cast (8009), пульт (6466)
и ADB (5555); хватит любого из них. В «Настройки → Удалённый доступ» — тот же список, что
работает удалённо, и пример правил ACL.

**Телефон.** Установите официальное приложение Tailscale, включите его и добавьте ТВ в Fling
по адресу Tailscale (он есть в приложении Tailscale) — так же, как ТВ добавляют по IP.

**Mac.** Внизу панели откройте меню ТВ («Сменить» / «ТВ») → **«ТВ в сети Tailscale…»** (оно же
в меню по правому щелчку на значке в строке меню: «Удалённый доступ (Tailscale)…»). В окне —
телевизоры вашей сети Tailscale с кнопкой **«Добавить»**, поле для адреса `100.x.y.z` или имени
MagicDNS, что работает вдали от дома и пример ACL. Fling сам находит консольный клиент Tailscale
(в Tailscale.app или из Homebrew) и только читает `tailscale status --json`. На Mac через
Tailscale работает пульт; трансляции вкладок через catt нужна домашняя сеть (см. ниже). ТВ,
связанный дома, Fling пробует с тем же ключом по адресу Tailscale; если ТВ попросит — свяжите
ещё раз («Связать» в панели).

Свяжите пульт и разрешите ADB **один раз дома** («Подключение ТВ»): связь продолжит работать
и через Tailscale.

## 3. Что работает удалённо

| Функция | Через Tailscale |
|---|---|
| Пульт: стрелки, громкость, приложения, набор текста, голос | Работает |
| ADB: установка APK, файлы, снимки экрана, консоль | Работает |
| Экран ТВ вживую (LIVE, scrcpy) | На компьютере работает; начинается с качества «Экономно» (960 px, 2 Мбит/с), другое выбирается в меню качества. LIVE на телефоне — новинка 0.4.1, качество подстраивается под сеть; проверьте и расскажите, как работает |
| Ссылка на ТВ для YouTube (Lounge) | Работает: она и так идёт через серверы YouTube |
| Трансляция ссылок (Cast, порт 8009) | Только если служба Cast на ТВ отвечает по адресу Tailscale. Fling проверяет это при добавлении; если нет — трансляция для этого ТВ отключается с понятным сообщением |
| Трансляция файлов с компьютера / телефона | Только если ТВ может подключиться к компьютеру в ответ (адрес Tailscale, брандмауэр); не гарантируется |
| Автоматический поиск ТВ (mDNS) | Через Tailscale не проходит — добавляйте ТВ по адресу |
| Bluetooth-пульт (Linux) | Только рядом |

Пока выбран ТВ из сети Tailscale, внизу панели видно **«через Tailscale · 38 мс»** (подсказка
говорит, прямое это соединение или через ретранслятор). Fling время от времени проверяет связь
с ТВ и, когда она возвращается после перерыва, сам переподключает пульт и ADB (пока ТВ
недоступен, проверяет всё реже). На компьютере ничего не слушает входящие подключения: Fling
только поддерживает свои собственные исходящие соединения.

## 4. Безопасность: ограничьте доступ к ТВ

ADB — это полный доступ к ТВ. При стандартном правиле Tailscale «разрешить всё» к порту ADB
на ТВ может подключиться **любое** устройство вашей сети. Ограничьте это правилами ACL:

1. В [консоли администратора](https://login.tailscale.com/admin/machines) откройте ТВ →
   *Edit ACL tags* → добавьте `tag:tv`.
2. В *Access controls* добавьте правило ниже (со своим логином) и уберите правило «всё всем»
   `{"src": ["*"], "dst": ["*:*"]}`, если оно есть.

```jsonc
{
  "tagOwners": {"tag:tv": ["you@example.com"]},
  "acls": [
    // only your own devices reach the TV, and only the ports Fling uses
    {"action": "accept", "src": ["you@example.com"],
     "dst": ["tag:tv:5555,6466,6467,8008,8009"]}
  ]
}
```

5555 — ADB, 6466/6467 — пульт Android TV, 8008/8009 — Cast (их можно убрать, если вы
не транслируете удалённо). И ещё: не делитесь ТВ (Share) с другими людьми и никогда
не открывайте эти порты через Tailscale Funnel или проброс портов на роутере.
